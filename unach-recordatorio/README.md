# Recordatorio UNACH

App Android que suena como alarma antes de las 7:00, a las 13:00, antes de las 15:00 y después de las 17:00
(por defecto 06:55, 13:00, 14:55 y 17:05; se pueden cambiar en la app). Al sonar ofrece
**Abrir Mi UNACH**, **Posponer 5 min** y **Ya registré**. El registro lo haces tú dentro de Mi UNACH.

## Instalar
1. En GitHub, pestaña **Actions** → ejecución más reciente de `unach-recordatorio-apk` → artefacto `recordatorio-unach-apk`.
2. Descarga y descomprime el zip en el teléfono, abre `app-debug.apk` y permite instalar desde esa fuente.
3. Abre la app, acepta las notificaciones y pulsa **Probar alarma**.
4. Recomendado: Ajustes → Batería → sin restricciones para esta app.
